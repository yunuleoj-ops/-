# 마법연산자

## 1. 이 SW의 특징
- 이 소프트웨어는 자기만의 마법진을 그리는 프로그램입니다.

### 1.1 제작 목적
- 사람들이 어린 시절 꿈꿨던 판타지를 구현하도록 만든 프로그램입니다.

### 1.2 주요 사용자
- 남녀노소 모두 사용할 수 있습니다.

### 1.3 차별점
- 자신의 마법진을 만들며 창의성을 키울 수 있고, 도형에 대한 이해를 키울 수 있습니다.

## 2. 이 SW의 기능
- 마법진을 원하는 모양으로 그리면 됩니다.

### 2.1 핵심 기능
- 마법진의 위력을 보여줍니다. 위력은 교차점, 대칭성, 선의 개수로 결정됩니다. 또한 그 도형을 나타내는 식도 도출됩나다.

### 2.2 보조 기능
- 속성과 이름도 지을 수 있습니다. 속성은 불, 바람, 물, 빛, 땅, 어둠속성이 있습니다. 공유 버튼도 있어서 자신이 만든 카드를 공유할 수 있습니다.

### 2.3 입력과 결과
- 한면은 그림, 한면은 식이 나옵니다.

## 3. 이 SW의 사용방법
- 원하는 마법진(도형)을 그려 넣고, 완성버튼을 누르면 됩니다.

### 3.1 접속 및 시작 방법
- 주소로 접근하여, 자유롭게 마법진을 그립니다.

### 3.2 주요 기능 사용 순서
- 마법진의 위력을 수학적으로 풀어나가는 것입니다.

### 3.3 사용 시 주의사항
- 신기하고 재밌어서 시간이 갑니다.
