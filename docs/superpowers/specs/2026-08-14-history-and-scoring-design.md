# 기록 복원과 999점 점수 체계

**목표:** 지우개와 전체 지우기까지 되돌릴 수 있게 하고, 획을 13개로 제한한 채 위력의 만점을 999로 다시 세운다.

## 1. 되돌리기 — 스냅샷 기록

### 지금의 문제

`historyReducer`의 되돌리기는 "획 배열의 마지막 원소를 빼서 redoStack 에 넣는다"이다. 그래서 두 가지를 되돌릴 수 없다.

- **지우개**: 가운데 획을 지우면 그 획은 어디에도 남지 않는다.
- **전체 지우기**: 양쪽 스택을 통째로 비운다.

되돌리기가 "마지막 획"이라는 특정 연산에 묶여 있는 것이 원인이다. 되돌려야 하는 것은 획이 아니라 **그림의 상태**다.

### 바꿀 형태

```ts
export type History = { past: Stroke[][]; present: Stroke[]; future: Stroke[][] };
```

- 상태를 바꾸는 액션(`commit` · `eraseAt` · `clear`)은 현재 `present`를 `past`에 밀어 넣고 `future`를 비운다.
- `undo`는 `past`의 마지막 칸을 `present`로 되돌리고 지금 `present`를 `future`로 보낸다. `redo`는 반대.
- `restore`(드래프트 불러오기)는 기록을 새로 시작한다 — 불러오기 이전으로 되돌아갈 자리는 없다.
- 아무것도 지우지 못한 지우개질은 기록하지 않는다. 빈 지우개질이 되돌리기 한 칸을 먹으면 안 된다.

획 객체는 만들어진 뒤 변형되지 않으므로 스냅샷은 참조 배열의 복사다. 그래도 무한히 쌓을 이유는 없어 `past`는 **50칸**까지만 유지한다(오래된 쪽부터 버린다).

리듀서가 순수해야 한다는 기존 제약은 그대로다 — StrictMode 가 리듀서를 두 번 실행해도 같은 결과가 나와야 한다.

## 2. 획 13개 제한

```ts
export const MAX_STROKES = 13;
```

- `commit`은 `present.length >= MAX_STROKES`이면 상태를 그대로 돌려준다. 제한을 리듀서가 지키므로 화면 어디에서 그리든 규칙이 하나다.
- `redo`는 제한을 검사하지 않는다. 다시 실행은 **이미 존재했던 상태로 돌아가는 것**이라, 여기서 막으면 13획을 넘긴 그림에서 지우개를 되돌릴 수 없다.
- 이미 13획을 넘은 그림(예전 드래프트, 공유 링크)은 그대로 보인다. 새 획만 들어가지 않는다.

화면에는 툴바에 `획 9/13`을 띄운다. 꽉 차면 그 표시가 강조되고, 펜으로 그려도 획이 커밋되지 않는다.

## 3. 위력 — 7개 지표, 만점 999

### 왜 다시 세우는가

현재 공식은 복사본 수(`copies`)가 사실상 지배한다. 13획 제한을 걸면 이론상 최대가 약 518점이라 999가 나올 수 없다.

### 지표와 배점

| 지표 | 만점 | 만점 조건 |
|---|---:|---|
| 획 수 | 120 | `lines / 13` |
| 닫힘 | 130 | `closed / lines` (모든 획이 닫힌 고리) |
| 회전 대칭 | 200 | `(rotation - 1) / 7` (회전 8회) |
| 거울 대칭 | 130 | 좌우 65 + 상하 65 |
| 교차 | 150 | `intersections / 28` |
| 꺾임 | 120 | `corners / 36` |
| 길이 | 150 | `length / 1100` |

각 항은 자기 만점에서 잘린다. 명목 합계는 1000이고 표시값은 `min(999, round(합))` — 마지막 1점까지 완벽해야 만점인 것이 아니라, 충분히 훌륭하면 999에 닿는다.

**999를 받는 그림:** 회전 8회 닫힌 획 11개 + 좌우 1개 + 상하 1개, 각진 도형으로 꼭짓점 36개 이상, 총 길이 1100 이상.

**매끈한 원만 그린 그림:** 꺾임이 0이라 880 언저리에서 멈춘다. 한 종류만 잘해서는 만점이 나오지 않는다.

### 등급

| 등급 | 하한 |
|---|---:|
| 초월 | 650 |
| 고급 | 400 |
| 중급 | 180 |
| 초급 | 0 |

### 파급

- `getMetrics`는 순수 함수이고 캔버스·완성 카드·공유 페이지·OG 이미지가 모두 이 함수를 부르므로, 한 곳만 고치면 네 화면이 함께 움직인다.
- **예전 그림과 공유 링크의 점수도 새 기준으로 다시 계산된다.** 그림 자체는 변하지 않는다.
- 위력 막대는 `power / 3.2`(최대 320 가정)로 폭을 잡고 있다. `power / 9.99`로 바꾼다.
- 항목별 점수를 카드에 보여주는 것은 이번 범위가 아니다.
